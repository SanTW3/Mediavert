# FishPilot — автопилот рыбалки для GPO

Программа для Grand Piece Online (Roblox, Windows). Сама забрасывает удочку, проходит мини-игру, ведёт список
улова и, если что-то пошло не так, **будит вас звонком на телефон**.

**Поддержать автора:** [donationalerts.com/r/etnealy](https://www.donationalerts.com/r/etnealy) — или кнопка
**♥ Поддержать автора** слева внизу в программе и внизу мини-приложения.

*[English](README.md) · Русский*

> FishPilot бесплатный (лицензия MIT) и **не связан с Roblox и Grand Piece Online**. Автоматизация может нарушать
> правила игры, за это могут забанить — пользуйтесь на свой риск. Программа предоставляется «как есть».
> Иконки рыб и названия принадлежат их владельцам.

## Запуск

1. Скачайте **FishPilot-win64.zip** из релиза [gpo-latest](https://github.com/SanTW3/Mediavert/releases/tag/gpo-latest).
2. Распакуйте архив в любую папку (не запускайте прямо из архива) и запустите `FishPilot\FishPilot.exe`.
   Python не нужен.
3. Windows SmartScreen может показать «Windows защитила ваш компьютер» — у программы нет платной подписи.
   Нажмите **Подробнее → Выполнить в любом случае**.

**Из исходников.** Установите Python 3.10+ (при установке отметьте «Add to PATH») и дважды кликните `run.bat`.
Собрать у себя: `build.bat` (папка `dist\FishPilot` и архив `dist\FishPilot-win64.zip`).

### Где лежат настройки

В `%APPDATA%\FishPilot`: `config.json` (настройки), `secrets.bin` (токены и секреты, зашифрованы Windows DPAPI —
их можно расшифровать только под вашей учётной записью), `fish_learned` (каталог рыб), `logs` (журнал ошибок).
Старые версии хранили всё рядом с exe — при первом запуске файлы переносятся сами.

**Программа → Помощь**: экспорт и импорт настроек (без токенов — файлом можно делиться с другом),
**Скопировать диагностику** (версия, система, конец лога, без секретов) и папка с логами.

### Обновления

Программа обновляется сама. При запуске (и раз в 6 часов) она проверяет релиз `gpo-latest`. Если там версия
новее, слева внизу появляется кнопка **⬆ Обновить до …**, а бот пишет об этом в Telegram. По кнопке программа
скачивает zip, проверяет SHA-256, после выхода заменяет файлы в своей папке и запускается снова.
Настройки в `%APPDATA%\FishPilot` не трогаются. Во время ловли обновление не ставится.
Новая версия публикуется только по тегу `fishpilot-vX.Y.Z`, а не после каждого изменения.

Версии 1.x (один exe `GPO-Fishing-Macro.exe`) обновятся как раньше, а затем программа один раз переедет
в папку `FishPilot` рядом со старым exe — дальше запускайте `FishPilot.exe` оттуда.

### Приватность

Программа ничего не собирает и не отправляет автору. В интернет уходит только то, что вы настроили:
сообщения и скриншоты (только окно Roblox) — в вашего Telegram-бота, тревоги — в ntfy/Pushover,
статус мини-приложения — через публичные MQTT-брокеры в подписанном виде (см. ниже), проверка обновлений — на GitHub.

## Первая настройка

При первом запуске откроется **гайд** по шагам. Снова открыть его можно кнопкой **«? Гайд по настройке»**
слева внизу. А на **Главной** всегда видно, что ещё осталось настроить.

1. Встаньте с удочкой у воды. Если нужна автопокупка наживки, встаньте у продавца (подсказка «E — Common Fish Bait»).
2. **Настройка → Слоты предметов**: *Слот удочки* — где лежит удочка, *Любой другой слот* — любой другой предмет.
   Перед каждым забросом макрос жмёт сначала «другой» слот, потом удочку: так удочка точно окажется в руках.
3. **Настройка → Заброс → Указать точку воды**: кликните по воде. *Удержание при забросе* — сколько держать ЛКМ,
   *Перезаброс через* — через сколько секунд без поклёвки перезабросить.
4. Поймайте одну рыбу вручную и, пока идёт мини-игра, нажмите **F2**. Выделите рамкой обе полосы
   (как зелёная рамка на скриншоте мини-игры).
5. **Что видит макрос** (Настройка → Область мини-игры) покажет разметку:
   пурпурная рамка — ваша тёмно-серая полоса, красная линия — рыба (белая черта), жёлтые — края трека.
   Если мини-игра не находится, в **Тонкая настройка → Распознавание** нажмите **Взять** и кликните по синему треку.
6. **F1** — старт/стоп, **F3** — выход, **F5** — HUD поверх игры. Клавиши меняются в разделе **Программа**.

## Как проходится мини-игра

На левой полосе синий трек, по нему ходит тёмно-серая полоса игрока: она поднимается, пока зажата ЛКМ,
и падает, когда кнопка отпущена. Белая черта — это рыба. PD-регулятор держит центр полосы на рыбе
(**Тонкая настройка → Мини-игра**):

- **Сила притяжения (Kp)** — насколько сильно тянуть полосу к рыбе;
- **Гашение (Kd)** — гасит раскачку (если полоса «перелетает» рыбу, увеличьте Kd или уменьшите Kp);
- **Ограничение** — предел выхода регулятора;
- **Тормоз при сближении** — множитель Kd, когда полоса уже едет к рыбе (тормозит, чтобы не перелететь);
- **Гашение при погоне** — когда рыба уходит от полосы;
- **Повтор нажатия ЛКМ** — повторять нажатие/отпускание, если оно не менялось, чтобы игра не «потеряла» кнопку;
- **Пауза после рыбы** — пауза после конца мини-игры (анимация поимки).

В **Распознавании** *Склейка полосы* решает, какие разрывы в тёмно-серой полосе склеивать (белая черта рыбы
рвёт её на две части; допуск = высота черты × множитель). Если в вашей версии игры полоса игрока синяя,
а трек тёмный, переключите *Полоса игрока* на `blue`.

## Автоматизация

- **Покупка наживки**: раз в *Покупать каждые* циклов покупает наживку в таком порядке:
  E → левая точка → средняя точка → ввод количества → левая точка → правая точка → средняя точка.
  С *Не покупать при старте* первая покупка будет только через заданное число циклов, а не сразу после старта.
- **Фрукты в хранилище**: после каждой рыбы берёт слот фрукта, кликает по точке Store,
  затем Shift → Backspace → Shift (задержки — в **Тонкая настройка → Задержки**).
- **Верхняя наживка**: перед забросом кликает по верхней наживке в списке.

**Чёрный экран античита** (**Тонкая настройка → Античит**): если чёрной стала доля окна Roblox больше *Порога чёрного экрана*
(0.85 = 85%) и через полсекунды экран всё ещё чёрный, макрос спамит клавишей *Клавиша* раз в
*Пауза между нажатиями*. Если экран не посветлел за *Тревога через* секунд, звонит будильник.
Если макрос прыгает, хотя экран не чёрный (очень тёмная ночь в игре, необычная графика),
поднимите порог или поставьте 0, чтобы выключить проверку. В журнале видно, сколько процентов окна было чёрным.

## HUD поверх игры

Пока идёт ловля, видны рамка области мини-игры (та, что выбирается на **F2**) и панель с показателями:
состояние макроса, время, рыб в час, поймано, забросов, последняя рыба, а во время мини-игры ещё
положение рыбы и полосы, ЛКМ и сколько кадров в секунду снимает макрос. Слева от рамки шкала:
фиолетовое — полоса игрока, красная черта — рыба.

HUD появляется после «Старт» и исчезает после «Стоп», и виден только поверх Roblox: если
переключиться на другое окно, он прячется. Он прозрачен для мыши, не забирает фокус,
а при чёрном экране прячется. На Windows 10 2004+ он не попадает в захват экрана.
Рамка, шкала и панель рисуются снаружи области мини-игры, так что распознаванию не мешают.
Включить или выключить HUD: **F5** или **Программа → Экран → HUD поверх игры**.

## Чёрный экран во время рыбалки

**Программа → Экран → Гасить экран после старта.** Через *Задержку перед затемнением* после «Старт» экран становится чёрным,
а макрос продолжает видеть игру: окно исключено из захвата экрана, клики и клавиши проходят сквозь
него в Roblox. Нужна Windows 10 версии 2004 или новее, на более старой Windows экран просто не
затемнится, и об этом появится запись в логе.

Вернуть экран:
- любая клавиша или кнопка мыши (нажатия самого макроса не считаются);
- горячая клавиша *Экран выкл / вкл* (F4), она же снова выключает экран;
- кнопка «🔆 Включить экран» в Telegram-боте.

Когда макрос останавливается (вручную или по тревоге), экран включается сам.

### Кнопки в Telegram

Если заполнены *Токен Telegram-бота* и *chat id* и включён *Кнопки управления в Telegram*, бот присылает
сообщение с кнопками: включить или выключить экран, скриншот (на нём игра, а не чёрное окно),
статус, остановить макрос. Меню можно вызвать в любой момент командой `/menu`.
Бот слушается только вашего chat id.

### Журнал улова

**Улов** и **Настройка → Уведомление о пойманной рыбе**. Журнал включён сразу. По умолчанию макрос ищет надпись **«New Item <Fangfish>»**
в центральной части окна Roblox, где она появляется над персонажем. Если у вас надпись в другом месте,
нажмите **Выбрать область** и выделите её. Рамку можно тянуть за углы
и края и двигать целиком. Enter или двойной клик сохраняет, Esc отменяет. После каждой мини-игры макрос
около двух секунд снимает эту область каждые 0,25 с и читает снимки встроенным распознаванием Windows (OCR).
Если надпись не нашлась, в журнале будет видно, что именно было прочитано.
Засчитывается только строка со словом «Item» («New Item <…>»). «Safe Zone Protected», названия островов
и другие надписи игры пропускаются, даже если OCR прочитал их с кавычками или скобками. **Проверить сейчас** покажет в журнале, что прочитано.

В Telegram кнопка **🐟 Улов** или команда `/catches` присылает картинку-список: иконка, название и сколько
поймано. Под списком есть кнопка **🗑 Очистить список**: бот переспросит, и после «Да, очистить» журнал очистится (то же делает команда `/reset_catches` и кнопка «Очистить» в мини-приложении). С *Сообщать о каждой рыбе* бот присылает каждую поимку.

#### Каталог рыб

В каталоге с самого начала все 16 рыб игры: иконки из инвентаря игры, редкость по цвету рамки и цена продажи
(все иконки, редкости и цены — со скринов инвентаря).
Названия для иконок подобраны по виду рыбы; если какое-то не совпадает, поправьте его в каталоге.

| Рамка | Редкость | Цвет названия |
|---|---|---|
| белая | обычная | белый |
| голубая | редкая | голубой |
| фиолетовая | эпическая | фиолетовый |
| радужная | легендарная | переливается радугой |

**Названия** берутся из уведомления «New Item <…>» (по-английски), **редкость** — по цвету названия
в уведомлении: голубой — редкая, фиолетовый — эпическая, разноцветный — легендарная, белый — обычная.
Свои названия можно вписать в **Улов → Каталог рыб**.

Названия подбираются **только из списка рыб игры**: Swordfish, Dark Skeletal Shark, Golden Ribbon Angelfish,
Golden Tigerfin, Golden Polka Puffer, Candy Corn Squid, Jack-O'-Bite, Skeletal Shark, Fangfish, Exotic Tigerfin,
Crimson Snapper, Zebra Ribbon Angelfish, Crimson Polka Puffer, Tigerfin, Blue-Lip Grouper, Anglerfish
(`KNOWN_NAMES` в `macro/fishdb.py`). Шрифт игры Windows OCR читает с ошибками, поэтому:

- допускаются перепутанные буквы, примерно каждая третья-четвёртая («Ansterfish» → Anglerfish);
- «<» перед названием OCR читает как букву («Czebra», «Cg0tden»), это учитывается;
- строку уведомления OCR иногда режет на куски, поэтому куски склеиваются, а обрезанное название
  узнаётся по словам («Dark Shark» → Dark Skeletal Shark, «Gotden Ribbon» → Golden Ribbon Angelfish);
- обрывок, который подходит к нескольким рыбам («Shark», «Crimson», «Putter»), не угадывается.

Если «New Item» прочитан, а название не похоже ни на одну рыбу, улов всё равно засчитывается как
**Unknown Fish**, а в журнал пишется, что именно прочитано. Новые названия в каталог больше не добавляются.
При запуске записи каталога с ошибками распознавания исправляются, а мусор удаляется.

**Рыбы из списка без иконки** (если в игру добавят новые и их впишут в `KNOWN_NAMES`) добавляются в каталог при первой поимке. В уведомлении нет иконки, поэтому у новой рыбы сначала
силуэт цвета её редкости. Если это рыба с иконкой со скрина, выберите её в **«Иконка со скрина…»**:
название перейдёт к настоящей иконке. Выученные рыбы хранятся в папке `%APPDATA%\FishPilot\fish_learned`.
Если в каталог попала ерунда, удалите её кнопкой **✕** в строке рыбы.
Если в списке есть легендарная рыба, бот присылает список анимацией: её название и рамка переливаются.

### Мини-приложение в Telegram

Живая панель внутри Telegram: пойманная рыба, забросы, время, старт/стоп, экран, скриншот,
сброс тревоги. Страница лежит в репозитории [SanTW3/gpo-macro](https://github.com/SanTW3/gpo-macro)
и публикуется через GitHub Pages. С макросом она общается через ntfy по топикам с секретным именем,
своего сервера нет.

После запуска макроса с настроенным ботом слева от поля ввода в чате появится кнопка **«Панель»**.
Ещё можно нажать **Отправить панель** (раздел **Телефон**) или отправить боту `/panel`.
Панель общается с макросом сразу через четыре публичных MQTT-брокера: `broker.emqx.io` и `broker.hivemq.com`
на портах 8084 и 8884, `mqtt.eclipseprojects.io` и `public.cloud.shiftr.io` на обычном порту 443 (мобильные сети
и VPN часто закрывают нестандартные порты). Список — настройка `mqtt_url` в `%APPDATA%\FishPilot\config.json`. Мини-приложение включается, только когда
настроен Telegram-бот. Если сеть не пускает
к одному брокеру, работает другой. Внизу панели мелким шрифтом видно, к каким брокерам она подключилась.
Лимита сообщений у брокеров нет, а последний статус хранится на брокере, поэтому панель показывает его сразу.
Брокеры публичные, поэтому имя топика — хэш секрета, а статус и команды подписаны секретом (HMAC-SHA256):
без ссылки на панель управлять макросом нельзя, а перехваченную команду нельзя повторить.

Если брокер недоступен, панель переходит на ntfy. У бесплатного ntfy.sh лимит около 250 сообщений в сутки,
поэтому через него статус уходит, только пока панель открыта (она раз в 30 с просит у ПК свежий статус),
и при старте, стопе, тревоге и смене экрана. В Telegram «📊 Статус» показывает, через какой канал панель на связи,
или ошибку.
Если ссылка на панель попала к кому-то ещё, нажмите **Новая ссылка**: старая ссылка перестанет работать.

## Будильник на телефон

Раздел **Телефон**. Можно настроить один канал или сразу несколько.

| Канал | Что нужно | Как звонит |
|---|---|---|
| **ntfy** (бесплатно, без регистрации) | Приложение ntfy (Android/iOS). Подпишитесь на тему с длинным уникальным именем, например `gpo-fish-k3j9x2`, и впишите это же имя в *Тема ntfy* | Уведомление с максимальным приоритетом. В настройках приложения для приоритета «max» включите звук будильника и «Override Do Not Disturb» |
| **Telegram** | Создайте **своего** бота через @BotFather (это *token*), откройте его и нажмите «Start», затем **Узнать chat id** | Сообщение со скриншотом экрана |
| **Pushover** (платное приложение, есть пробный период) | *User key* и *API token* из pushover.net | Экстренный приоритет: телефон звонит каждые 30 с, пока вы не нажмёте «Acknowledge». Ближе всего к настоящему будильнику |

### Если Telegram-бот молчит

Нажмите **Проверить Telegram** (раздел **Телефон**). Программа по шагам проверит токен, chat id и отправку
сообщения и напишет в журнал, что не так:

- *неверный токен* — скопируйте токен у @BotFather заново, целиком (вида `123456789:AAE…`);
- *chat not found* / *бот не может написать вам* — откройте бота в Telegram, нажмите «Start», затем **Узнать chat id**;
- *в chat id вписан id самого бота* — нужен ваш id, его найдёт **Узнать chat id**;
- *бот уже запущен в другой программе* — один бот нельзя использовать на двух ПК: у друга должен быть свой бот;
- *нет связи с api.telegram.org* — Telegram у провайдера заблокирован: включите VPN на ПК.

Ошибки бота во время работы тоже пишутся в журнал.

*Повторять тревогу* повторяет тревогу, пока вы не нажмёте **Стоп тревоги** или снова **F1**.
**Тест тревоги** присылает пробное уведомление.

### Когда звонит (Watchdog)

- N забросов подряд без поклёвки. Так проявляются кончившаяся наживка, дисконнект или сдвинутый персонаж.
- Ни одной рыбы за N минут.
- Окно Roblox закрыто или неактивно дольше N секунд: игра вылетела или окно свернули.
- Чёрный экран античита не уходит.
- Макрос упал с ошибкой.

С галочкой *Останавливать макрос при тревоге* макрос при тревоге останавливается и отпускает мышь.
