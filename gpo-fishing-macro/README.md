# GPO Fishing Macro

Макрос рыбалки для Grand Piece Online (Roblox, Windows). Сам забрасывает удочку, проходит мини-игру
и, если что-то пошло не так, **будит вас звонком на телефон**.

## Запуск

1. Установите Python 3.10+ (при установке отметьте «Add to PATH»).
2. Дважды кликните `run.bat`: он поставит зависимости и откроет окно.
   Чтобы собрать один `GPO-Fishing-Macro.exe`, запустите `build.bat` (результат в `dist\`).

Настройки сохраняются в `config.json` рядом с программой.

## Первая настройка

1. Встаньте с удочкой у воды. Если нужна автопокупка наживки, встаньте у продавца (подсказка «E — Common Fish Bait»).
2. **General**: клавиши слотов. *Rod Hotkey* — слот удочки, *Anything Else Hotkey* — любой другой слот.
   Перед каждым забросом макрос жмёт сначала «другой» слот, потом удочку: так удочка точно окажется в руках.
3. **Casting → Set Water Point**: кликните по воде. *Cast Hold Duration* — сколько держать ЛКМ при забросе,
   *Recast Timeout* — через сколько секунд без поклёвки перезабросить.
4. Поймайте одну рыбу вручную и, пока идёт мини-игра, нажмите **F2**. Выделите рамкой обе полосы
   (как зелёная рамка на скриншоте мини-игры).
5. **Literally Everything Else → Debug Preview** покажет, что видит макрос:
   пурпурная рамка — синяя зона, красная линия — рыба (белая черта).
   Если зона не находится, нажмите **Pick from screen** и кликните по синей зоне.
6. **F1** — старт/стоп, **F3** — выход. Клавиши меняются кнопками *Rebind*.

## Как проходится мини-игра

На левой полосе синяя зона: она поднимается, пока зажата ЛКМ, и падает, когда кнопка отпущена.
Белая черта — это рыба. PD-регулятор (*Fishing*) держит центр зоны на рыбе:

- **Kp** — насколько сильно тянуть зону к рыбе;
- **Kd** — гасит раскачку (если зона «перелетает» рыбу, увеличьте Kd или уменьшите Kp);
- **PD Clamp** — ограничение выхода регулятора;
- **Fish End Delay** — пауза после конца мини-игры (анимация поимки).

## Pre-Cast

- **Auto Buy Common Bait**: раз в *Loops Per Purchase* циклов нажимает E у продавца и кликает
  по трём заданным точкам: левая, средняя, правая. Если средняя точка — поле количества,
  включите *Type amount into Middle Point*, и макрос впишет туда число циклов.
- **Auto Store Devil Fruit**: после каждой рыбы берёт слот фрукта, кликает по точке Store,
  затем Shift → Backspace → Shift (задержки — в последней вкладке).
- **Auto Select Top Bait**: перед забросом кликает по верхней наживке в списке.

## Literally Everything Else

Задержки как в оригинале: фокус окна Roblox, покупка наживки (E, клики, ввод количества,
анти-детект микрозадержка), сохранение фрукта, выбор наживки, этапы рыбалки
(выбор удочки, задержка после движения курсора, период сканирования цвета) и
*Approaching Damping Multiplier* — во сколько раз усиливать Kd, когда зона уже едет к рыбе.

**Anti-Macro Black Screen Detection**: если чёрным стало больше *Black Screen Threshold*
экрана (0.5 = 50%), макрос спамит клавишей *Spam Key* раз в *Key Spam Delay*.
Если экран не посветлел за *Alarm After* секунд, звонит будильник.

## Будильник на телефон

Вкладка **Literally Everything Else → Phone Alarm**. Можно настроить один канал или сразу несколько.

| Канал | Что нужно | Как звонит |
|---|---|---|
| **ntfy** (бесплатно, без регистрации) | Приложение ntfy (Android/iOS). Подпишитесь на тему с длинным уникальным именем, например `gpo-fish-k3j9x2`, и впишите это же имя в *ntfy topic* | Уведомление с максимальным приоритетом. В настройках приложения для приоритета «max» включите звук будильника и «Override Do Not Disturb» |
| **Telegram** | Создайте бота через @BotFather (это *token*), напишите ему что-нибудь, потом узнайте свой *chat id* (например, у @userinfobot) | Сообщение со скриншотом экрана |
| **Pushover** (платное приложение, есть пробный период) | *User key* и *API token* из pushover.net | Экстренный приоритет: телефон звонит каждые 30 с, пока вы не нажмёте «Acknowledge». Ближе всего к настоящему будильнику |

*Repeat alarm every* повторяет тревогу, пока вы не нажмёте **Stop Alarm** или снова **F1**.
**Test Alarm** присылает пробное уведомление.

### Когда звонит (Watchdog)

- N забросов подряд без поклёвки. Так проявляются кончившаяся наживка, дисконнект или сдвинутый персонаж.
- Ни одной рыбы за N минут.
- Окно Roblox закрыто или неактивно дольше N секунд: игра вылетела или окно свернули.
- Чёрный экран античита не уходит.
- Макрос упал с ошибкой.

С галочкой *Stop macro on alarm* макрос при тревоге останавливается и отпускает мышь.

## Заметки

- Roblox должен быть активным окном. Масштаб Windows не важен: программа DPI-aware.
- Цвета по умолчанию сняты со скриншота мини-игры. Если в игре другая графика, подстройте
  *Color tolerance* и *Fish line brightness*, проверяя результат в Debug Preview.
- Тесты: `python -m pytest tests`.
