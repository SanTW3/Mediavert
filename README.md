# Mediavert

Конвертер аудио, видео и картинок для Windows. Работает без интернета, ffmpeg встроен.

## Установка

Запустите `dist\Mediavert-Setup-<версия>.exe`. Права администратора не нужны, программа ставится в профиль пользователя.
После установки Mediavert живёт в трее (возле часов).

## Три способа конвертировать

1. **«Челка» сверху экрана.** Перетащите файл к верхнему краю экрана, по центру. Тонкая полоска раскроется в панель с форматами: бросьте файл на «WAV», «MP3», «MP4»… Готовый файл можно **вытащить мышкой прямо из челки** в любую программу, мессенджер или папку. Клик по полоске показывает последние результаты.
2. **Меню Проводника.** Правый клик по файлу → «Конвертировать в…» → формат. Включается в ⚙ настройках или в меню трея. В Windows 11 пункт находится в «Показать дополнительные параметры» (Shift+F10).
3. **Главное окно.** Тут всё вручную: пачка файлов, пресеты (для телефона, для iPhone, компактно, голос и подкасты, ровная громкость, без потерь, для видеомонтажа, для CD), нормализация громкости, срез тишины, fade, обрезка, разрешение/FPS для видео, размер и качество для картинок.

Челка и меню Проводника берут настройки качества из главного окна (разрядность, частота, битрейт, нормализация и т.д.).
По умолчанию файлы сохраняются **рядом с исходником**. В ⚙ можно выбрать отдельную папку.

## Форматы

- **Аудио:** WAV, AIFF, FLAC, ALAC, MP3, AAC, OGG, Opus
- **Видео:** MP4, MOV (H.264), MOV (ProRes), MKV, WebM, GIF; звук из видео в любой аудиоформат; кадр в PNG/JPG
- **Картинки:** PNG, JPG, WebP, BMP, TIFF, ICO

## Автообновление через GitHub

Установленный Mediavert сам проверяет GitHub Releases: при запуске и раз в 4 часа. Новую версию он скачивает в фоне,
показывает кнопку «Обновить до …» в шапке и уведомление, а если её не нажать — ставит обновление при следующем выходе из программы.

Релизы публикуются в отдельный публичный репозиторий [SanTW3/Mediavert-releases](https://github.com/SanTW3/Mediavert-releases/releases/latest) —
код при этом может быть приватным. Публикация: `npm.cmd run release` (токену нужен доступ Contents: Read and write
ко всем репозиториям из `build.publish`).
