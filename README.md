# Mediavert

Конвертер аудио, видео и картинок для Windows. Работает без интернета, ffmpeg встроен.

## Установка

Запустите `dist\Mediavert-Setup-<версия>.exe`. Права администратора не нужны, программа ставится в профиль пользователя.
После установки Mediavert живёт в трее (возле часов).

## Три способа конвертировать

1. **«Челка» сверху экрана.** Перетащите файл к верхнему краю экрана, по центру. Тонкая полоска раскроется в панель с форматами: бросьте файл на «WAV», «MP3», «MP4»… Готовый файл можно **вытащить мышкой прямо из челки** в DAW, мессенджер или папку. Клик по полоске показывает последние результаты.
2. **Меню Проводника.** Правый клик по файлу → «Конвертировать в…» → формат. Включается в ⚙ настройках или в меню трея. В Windows 11 пункт находится в «Показать дополнительные параметры» (Shift+F10).
3. **Главное окно.** Тут всё вручную: пачка файлов, пресеты (DAW 24/48, мастер, CD, сэмплы, MP3 320, −14 LUFS, FLAC, ALAC), нормализация громкости, срез тишины, fade, обрезка, разрешение/FPS для видео, размер и качество для картинок.

Челка и меню Проводника берут настройки качества из главного окна (разрядность, частота, битрейт, нормализация и т.д.).
По умолчанию файлы сохраняются **рядом с исходником**. В ⚙ можно выбрать отдельную папку.

## Форматы

- **Аудио:** WAV, AIFF, FLAC, ALAC, MP3, AAC, OGG, Opus
- **Видео:** MP4, MOV (H.264), MOV (ProRes), MKV, WebM, GIF; звук из видео в любой аудиоформат; кадр в PNG/JPG
- **Картинки:** PNG, JPG, WebP, BMP, TIFF, ICO

## Автообновление через GitHub

Установленный Mediavert сам проверяет GitHub Releases: при запуске и раз в 4 часа. Новую версию он скачивает в фоне,
показывает кнопку «Обновить до …» в шапке и уведомление, а если её не нажать — ставит обновление при следующем выходе из программы.

Один раз:

1. Создайте **публичный** репозиторий на GitHub (например, `mediavert`).
2. В `package.json` → `build.publish` впишите свой логин в `owner` и имя репозитория в `repo`.
3. Создайте токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained,
   доступ только к этому репозиторию, право **Contents: Read and write**.

Каждый выпуск:

1. Увеличьте `version` в `package.json` (например, 2.5.0 → 2.5.1).
2. В PowerShell:
   ```
   $env:GH_TOKEN = "ваш_токен"
   npm.cmd run release
   ```
   Сборщик создаст релиз `v2.5.1` и загрузит туда установщик и `latest.yml` — у всех пользователей обновление
   появится само. Токен никому не передавайте и не сохраняйте в файлах проекта.

## Разработка

```
npm install
node node_modules/electron/install.js   # если npm не запустил install-скрипт Electron
npm start                                # запуск из исходников
npm run dist                             # сборка установщика в dist/
```

Структура:

- `electron/main.js`: окна, трей, челка, IPC
- `electron/jobs.js`: очередь конвертаций
- `lib/convert.js`: параметры ffmpeg
- `renderer/`: интерфейс главного окна (`index.html`) и челки (`shelf.html`)
- `scripts/make-assets.js`: иконка и скрипт очистки реестра для деинсталлятора
- `electron/selftest.js`: автопроверка (`MEDIAVERT_SELFTEST=<папка>`), в сборку не входит
