    Добро пожаловать в Mediavert

    Конвертер для музыкантов и не только: WAV, MP3, FLAC, AIFF, видео, GIF, картинки. Всё работает прямо на компьютере — без интернета и загрузок на сервер.

    Покажем за минуту три способа конвертировать.

    Перетащите файлы сюда
    MP3beat.mp3WAV ⌄
    Конвертировать

    Главное окно

    1. Перетащите файлы в окно — можно сразу пачку.
    2. У каждого файла выберите формат, справа — качество и пресеты.
    3. Нажмите «Конвертировать». Готовый файл можно перетащить мышкой прямо в DAW или папку.
    WAVMP3FLACMP4GIF
    vocal.wav

    «Челка» сверху экрана

    Наверху по центру экрана есть тонкая полоска. Тащите любой файл к верхнему краю — она раскроется, отпустите файл на нужный формат.

    Когда готово — вытащите результат прямо из челки в FL Studio, Ableton или Telegram. Клик по полоске покажет последние файлы.

    Правый клик в Проводнике

    Щёлкните правой кнопкой по файлу → «Конвертировать в…» → формат. Работает и с несколькими выделенными файлами.

    В Windows 11 пункт находится в «Показать дополнительные параметры» (или Shift+F10).

    Как пользоваться Папка Настройки
    ⌃ 12:00

    Настройки и трей

    Кнопка «Настройки» вверху окна: куда сохранять файлы (по умолчанию — рядом с исходником), челка, меню Проводника, тема оформления.

    Если закрыть окно, Mediavert продолжит работать в трее возле часов — челка и меню останутся доступны.

    Цвет оформления

    Выберите акцентный цвет — им подсвечиваются кнопки, переключатели и челка.
